# EIAP v1.0.0 — Enterprise Intelligence Automation Platform

We are proud to announce the official **v1.0.0** release of the **Enterprise Intelligence Automation Platform (EIAP)** — a production-grade, end-to-end Business Intelligence and AI Automation Platform engineered for enterprise operational excellence.

EIAP coordinates automated ingestion, data quality validation, transactional dimensional ETL, business KPI tracking, statistical anomaly detection, grounded executive intelligence generation, automated responsive email distribution, and self-healing operational incident recovery.

---

## 🌟 Key Architectural Capabilities

### 1. Eight Core n8n Production Workflows (`workflows/`)
- **WF01 — Enterprise Data Ingestion (`01-data-ingestion.json`):** Webhook-driven batch ingestion supporting CSV and REST API payloads. Features SHA-256 batch payload hashing, correlation ID propagation (`X-Correlation-ID`), and idempotent replay detection.
- **WF02 — Enterprise Data Quality Engine (`02-data-quality.json`):** Seven deterministic validation gates (presence, format, numeric bounds, dates, ISO-4217 currencies, referential integrity, and business duplicate keys). Automatically routes defective records to an auditable quarantine table (`rejected_records`).
- **WF03 — Enterprise SQL ETL Pipeline (`03-sql-etl.json`):** Atomic transactional dimensional loader transforming validated raw data into an optimized star schema warehouse (`fact_orders`, `dim_date`, `dim_product`, `dim_geography`).
- **WF04 — Power BI Semantic Model Refresh (`04-powerbi-refresh.json`):** Asynchronous dataset refresh orchestration with polling, exponential backoff, timeout protection, and automated incident raising on failure.
- **WF05 — Executive KPI Aggregation & Anomaly Detection (`05-kpi-monitoring.json`):** Single-currency financial KPI aggregation engine (Revenue, Cost, Profit, Margin %, AOV, Cancellation Rate) paired with statistical anomaly detection (revenue spikes, margin degradation) and 24-hour alert suppression.
- **WF06 — AI Executive Narrative Intelligence (`06-ai-insights.json`):** Grounded executive briefing generation structuring insights across 7 standardized operational sections with strict mathematical verification against authoritative PostgreSQL ledger figures to eliminate hallucinations.
- **WF07 — Executive Report Email Distribution (`07-report-distribution.json`):** Automated delivery of modern, responsive HTML briefings to enterprise stakeholders with dispatch idempotency to guarantee zero duplicate emails.
- **WF08 — Operational Failure Recovery & Self-Healing (`08-failure-recovery.json`):** Autonomous error handler classifying failures into transient vs. permanent categories. Executes exponential backoff with full jitter and automatically routes exhausted retries to a Dead Letter Queue (DLQ).

### 2. High-Performance FastAPI Backend (`apps/api/`)
- Built on Python 3.12, FastAPI, Pydantic v2, and SQLAlchemy 2.0.
- Implements 7 modular endpoint groups: `/v1/ingestion`, `/v1/quality`, `/v1/etl`, `/v1/kpis`, `/v1/anomalies`, `/v1/ai`, `/v1/reports`, `/v1/operations`, `/v1/integrations`.
- Timing middleware injecting `X-Correlation-ID` and `X-Response-Time-Ms` across all responses.
- API key authentication with constant-time comparison against timing attacks.

### 3. PostgreSQL 16 Analytics Star Schema (`apps/api/migrations/`)
- 12 fully indexed, foreign-key-constrained relational warehouse tables managed via version-controlled Alembic migrations (`001_initial_schema`, `002_phase4_intelligence_and_ops`).
- Enforces strict grain uniqueness on `fact_orders` via `uq_fact_orders_grain`.

### 4. Zero-Cost, Reproducible Docker Stack (`docker-compose.yml`)
- Orchestrates 4 isolated container services: `eiap_n8n`, `eiap_api`, `eiap_postgres`, and `eiap_mailpit`.
- Configured with internal Docker bridge networking, healthchecks, persistent named volumes, and localhost-only port binding (`127.0.0.1`).

## ⚠️ Important Implementation & Demonstration Considerations

1. **Synthetic Demonstration Data:**
   - All demonstration datasets (`data/fixtures/standard_10k.csv` and `smoke_100.csv`) are deterministically generated by `data/generators/seed_generator.py` using fixed random seeds. They contain controlled synthetic defects (missing fields, negative quantities, invalid currencies, intentional revenue spikes) for demonstration and testing purposes only.

2. **Local Mock Adapters:**
   - In default local demonstration mode, the platform operates with `POWERBI_ADAPTER=mock` and `AI_PROVIDER=mock` enabled. This guarantees 100% offline, zero-cost, reproducible execution without requiring paid Microsoft Fabric or OpenAI/Claude API licenses. Production deployment simply requires toggling feature flags in `.env` and providing cloud credentials.

3. **Email Delivery via Mailpit:**
   - By default, all outbound report emails from WF07 are routed to the embedded local Mailpit catcher (`127.0.0.1:8025`). No external email relays are engaged, eliminating any risk of unintended external email delivery during testing.

4. **Performance Benchmarking Limitations:**
   - Performance benchmarks reported in documentation (e.g. 5,900+ rows/sec bulk ingest, sub-50ms API latencies) were gathered on a standard local workstation running Docker Desktop on Windows 11. Production cloud throughput will vary based on allocated vCPU, memory, storage IOPS, and network latency.

5. **n8n Version & Credential Architecture:**
   - This release is pinned and verified against **n8n v1.82.2**.
   - All exported workflow JSON files in `workflows/` utilize n8n generic credential types (`httpHeaderAuth` and `postgresDb`). Real credentials must never be exported into workflow definitions; they are managed securely inside n8n's encrypted internal SQLite/PostgreSQL credential store.

## 📦 Getting Started

To launch the full platform locally in under 5 minutes:

```bash
# Clone the repository
git clone https://github.com/sabledattatray/enterprise-n8n-intelligence-automation.git
cd enterprise-n8n-intelligence-automation

# Copy environment configuration
cp .env.example .env

# Start Docker containers
docker compose up -d

# Run Alembic migrations and seed database
docker compose exec api alembic upgrade head
docker compose exec api python scripts/seed_database.py
```

Access the interfaces:
- **n8n Web UI:** [http://127.0.0.1:5678](http://127.0.0.1:5678)
- **FastAPI Documentation:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **Mailpit Email Inspector:** [http://127.0.0.1:8025](http://127.0.0.1:8025)
